# 📄 CORE PARSER SPECIFICATION
> **비정형 마크다운 파일 디코딩 및 유저별 발화 격리 엔진 설계 명세서**

본 문서는 사용자가 제출한 마크다운 자산으로부터 메타데이터와 정적 토큰을 추출하는 `mdStaticParser` 및 다중 사용자 대화 스트림에서 특정 대상의 컨텍스트를 분리하는 `scriptSplitter` 모듈의 아키텍처 규칙과 예외 방어 가이드라인을 정의합니다.

---

## 🔏 1. 정적 마크다운 토큰 파서 (mdStaticParser)

`mdStaticParser`는 외부 서드파티 무거운 라이브러리(예: Marked, Unified)에 의존하지 않고, 경량 가동 및 메모리 격리를 달성하기 위해 TypeScript 네이티브 문자열 파싱 기법으로 구현되었습니다.

### ⚙️ 데이터 추출 및 파싱 토큰 명세
*   **YAML Front Matter:** 파일 최상단의 `---` 기호로 격리된 블록을 행 단위로 split하여 `key: value` 사전형 구조체로 변환합니다. 문자열 외곽의 싱글/더블 따옴표는 정규식을 통해 자동 보정됩니다.
*   **인용구 기호 (`> `):** 해당 행이 `>` 토큰으로 시작하는 경우, 텍스트 버퍼에서 기호를 거르고 유저가 정의한 '핵심 목표 및 인지적 상태' 문자열로 포획합니다.
*   **할 일 목록 기호 (`- [ ]`, `- [x]`):** `- [`로 시작하는 체크리스트 행을 분석하여 공백(` `)인 경우 `completed: false`, `x` 또는 `X` 기호가 채워진 경우 `completed: true` 형태의 불리언 값으로 엄격 매핑합니다.

### 🛡️ 크래시 방어 가이드라인 (Error Defense)
1.  **Front Matter 미폐쇄 예외:** 파일 내부에 첫 번째 `---`만 존재하고 닫는 `---`가 유실된 경우, 파서는 시스템 다운을 막기 위해 파일 전체를 일반 `rawBody`로 자동 이관 처리합니다.
2.  **공백 및 개행 무력화:** 유저가 개행을 난사하거나 기호 사이에 무작위 공백을 삽입하더라도 문법이 터지지 않도록 `.trim()` 및 정규식 `^\s*` 패턴을 선제 적용합니다.

## ✂️ 2. 다중 발화 스크립트 스플리터 (scriptSplitter)

`scriptSplitter`는 여러 사용자가 한데 뒤섞여 대화한 단톡방이나 커뮤니티의 텍스트 덤프 로그(`global_script_w1.md`)로부터, 지정된 특정 대상 닉네임의 실전 행동 기록(`Did`)만을 완벽하게 분리 추출하는 필터 인터페이스입니다.

### 🧩 비정형 대화 표기법 대응 매칭 매트릭스
라이브 데이터의 비정형 특성을 소화하기 위해 스플리터는 총 3단계의 정규식 매칭 레이어를 순차적으로 구동하여 발화를 스캔합니다.

| 우선순위 | 타겟 텍스트 패턴 예시 | 대응 정규식 (Regex Pattern) | 파싱 결과 분리 가이드 |
| :--- | :--- | :--- | :--- |
| **1순위** | `**EasyPeasy**: 오늘 성공!` | `/^\s*\*\*(.*?)\*\*?\s*:\s*(.*)/` | 볼드 기호 내부 문자열을 닉네임으로 추출 |
| **2순위** | `[EasyPeasy] 단어 외움` | `/^\s*\[(.*?)\]\s*:?\s*(.*)/` | 대괄호 내부 문자열을 닉네임으로 추출 |
| **3순위** | `EasyPeasy: 소리 읽기 완료` | `/^\s*([^:\s]+)\s*:\s*(.*)/` | 콜론(:) 이전의 연속된 문자열을 닉네임으로 추출 |

### 🛡️ 컨텍스트 오염 방어 가이드라인 (Context Separation)
*   **마크다운 토큰 충돌 우회:** 인용구 기호(`> `)나 할 일 목록 기호(`- [ ]`)가 포함된 행이 우연히 콜론(`:`)을 가지고 있더라도 대화록 발화 데이터로 오인되지 않도록, 해당 행들은 3순위 일반 명사 매칭 대상에서 철저히 제외시킵니다.
*   **대소문자 및 공백 무감각 화(Insensitivity):** 유저 닉네임 검색 시 대소문자 구분을 없애고(`toLowerCase()`) 외곽 공백을 완전히 거세하여, `easypeasy`나 `EasyPeasy ` 모두 동일 인물 컨텍스트로 묶어 처리합니다.
