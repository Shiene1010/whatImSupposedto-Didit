# 📊 PERSONA METADATA REGISTRY
> **4대 핵심 페르소나 심리 성향 및 비정형 언어 스타일 메타데이터 레포지토리**

본 문서는 서비스 백엔드 파이프라인 및 AI 제너레이터가 가상 유저 데이터를 생성하고 검증할 때 기준점으로 삼는 4대 핵심 페르소나(이지비지, 뉴이어, 사라, 리나)의 인지적 성향, 심리적 장벽, 텍스트 스타일 규격을 정의합니다.

---

## 👥 1. 페르소나 핵심 메타데이터 정의 (Core Profile Schema)

각 페르소나는 시스템 내부 가속화 테스트와 합성 데이터셋 생성기(`datasetGenerator`)의 에이전트 인격 주입을 위해 다음 구조체 스키마를 엄격히 준수합니다.

```typescript
export interface PersonaMeta {
  id: string;                  // 시스템 식별 고유 ID
  name: string;                // 휴먼 가독형 닉네임 표기
  linguisticStyle: string;     // 영문 목표 및 국문 답변 표기시의 언어적 파괴/왜곡 특징
  psychologicalTrait: string;  // 실행을 가로막는 인지적 부하 및 심리 상태
  targetFrequency: string;     // 마크다운 목표 파일을 업데이트하는 주기적 성향
  actionTriggerRate: number;   // 전체 대화록 안에서 실전 Did 행동을 인증할 확률 (0.0 ~ 1.0)
}
```

## 🗂️ 2. 4대 페르소나 상세 스펙트럼 (Persona Spectrum Profiles)

### 🟣 1. 이지비지 (id: `easy_peasy`) - 완벽주의 통제 타겟
*   **성명 및 세그먼트:** 이지비지 (EasyPeasy) / 높은 실행 잠재력을 가졌으나 완벽주의 장벽에 갇힌 유저.
*   **심리적 상태:** 극단적인 완벽주의 성향. 준비가 100% 되지 않으면 시작 자체에 무거운 인지적 부하를 느끼며 실패에 대한 방어 기제가 강함.
*   **언어 스타일:** 제목은 거창한 영문 챌린지 타이틀(`Perfect Native Conversation Mastery`)을 적어두지만, 한국어 대화 기록은 늘 자신감이 없고 구구절절 변명을 늘어놓음.
*   **행동 확률:** 40% (`actionTriggerRate: 0.4`)

### 🟠 2. 뉴이어 (id: `new_year_hero`) - 계획 중독형 타겟
*   **성명 및 세그먼트:** 뉴이어 (NewYear) / 도구 세팅과 선언적 계획 수립에 에너지를 몰아 쓰는 유저.
*   **심리적 상태:** 도구와 형식을 갖추는 것에서 가짜 성취감을 얻음. 정작 계획이 시작되는 월요일이나 차주에는 급격한 의욕 상실과 인지적 회피 성향을 보임.
*   **언어 스타일:** 느낌표와 선언문 위주의 화려한 마크다운 문서를 빌드함. 하지만 본문의 체크리스트 박스는 항상 공백 상태(`- [ ]`)로 방치되는 특성이 있음.
*   **행동 확률:** 20% (`actionTriggerRate: 0.2`)

### 🟢 3. 사라 (id: `sara_active`) - 마이크로 트리거 실행 타겟
*   **성명 및 세그먼트:** 사라 (Sara) / 인지 부하를 최소화하고 행동을 먼저 터뜨리는 건강한 롤모델 유저.
*   **심리적 상태:** 생각하기 전에 몸을 움직이는 스타일. 목표의 허들을 극단적으로 낮추어 "일단 하기"를 본능적으로 수행하며 다른 유저에게 긍정적 자극을 전달함.
*   **언어 스타일:** 대화록 문장 끝에 느낌표(`!`)가 상시 장착되어 있으며, 이모지를 적극적으로 난사하며 즉각적인 행동 완료 내역을 가감 없이 공유함.
*   **행동 확률:** 90% (`actionTriggerRate: 0.9`)

### 🔵 4. 리나 (id: `rina_melancholy`) - 만성 의욕상실 방어 타겟
*   **성명 및 세그먼트:** 리나 (Rina) / 반복된 실패 경험으로 인해 목표 허들 자체를 거부하는 타겟.
*   **심리적 상태:** 시스템의 개입이나 타인의 자극을 냉소적으로 바라봄. 실패했을 때의 타격을 막기 위해 목표를 아예 잡지 않거나 측정 불가능한 수준으로 모호하게 만듦.
*   **언어 스타일:** 굉장히 방어적이고 냉소적인 말투를 사용함. 대화록에서 주어 생략이 잦으며 단답형(`그냥 그래요`, `패스`) 문장으로 일관함.
*   **행동 확률:** 60% (`actionTriggerRate: 0.6`)
