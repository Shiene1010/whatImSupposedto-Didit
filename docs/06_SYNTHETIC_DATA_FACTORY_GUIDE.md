# 🤖 SYNTHETIC DATA FACTORY GUIDE
> **AI 기반 대량 가상 마크다운 자산 양산 및 시뮬레이션 가이드 라인**

본 문서는 서비스 운영 및 인프라 통합 스트레스 테스트를 위해 가상 페르소나의 왜곡된 인격을 시뮬레이션하고, 대규모 마크다운 데이터셋 자산 쌍을 디스크에 물리적으로 자동 생성(Dump)하는 `datasetGenerator` 프로덕트의 운용 규격을 정의합니다.

---

## 🏭 1. 양산 엔진 아키텍처 철학 (Philosophy)

*   **비정형 한계점 도출 (Edge Case Probing):** 소수의 이상적인 샘플 데이터만으로는 실제 운영 환경의 무작위 텍스트 오염과 문법 깨짐 리스크를 전수 방어할 수 없습니다. 
*   **합성 데이터 허브 (Synthetic Generation Hub):** `datasetGenerator.ts` 엔진은 정의된 페르소나 프로필을 기반으로 AI가 스스로 '모호한 영어 목표'와 '현실적인 한글 변명/인증 발화' 조합을 역으로 대량 생산하게 유도하여 가속화 테스트 인프라를 구축합니다.

---

## ⚙️ 2. 파이프라인 및 데이터 덤프 메커니즘 (Dump Mechanism)

제너레이터 스크립트는 Node.js 환경에서 디스크 파일 I/O 시스템과 OpenAI GPT-4o API를 결합하여 동작합니다.

```text
[PERSONA_REGISTRY 로드] ➜ 페르소나 메타정보 분석 (성향 및 언어 스타일 추출)
                             │
                             ▼
[프롬프트 에이전트 빌드]    ➜ 각 인격체 빙의 지침 및 엄격한 텍스트 구분자(===) 주입
                             │
                             ▼
[GPT-4o API 호출]         ➜ 높은 온화도(Temperature 0.8) 설정을 통한 비정형 변형 텍스트 유도
                             │
                             ▼
[스트링 분리 및 파일 덤프]  ➜ 구분자 기준 분할 후 `assets/stage_03_generated/` 폴더에 .md로 적재
```

### 🧱 3종 엄격 구분 파일 적재 규칙
생성 엔진은 단 한번의 LLM API 추론으로 완벽히 쌍을 이루는 마크다운 정적 자산을 추출하기 위해 물리적 구분 기호(`===`) 기법을 집행하며, 분리 완료 시 다음 2종의 물리적 덤프 파일 자산 세트가 지정 디렉토리에 누적 생성됩니다.
1.  **목표 파일 덤프:** `${personaId}_synthetic_target.md` ➜ YAML Front matter와 인용구, 체크리스트를 포함한 유저 인격 맞춤형 모호한 목표서.
2.  **발화 파일 덤프:** `${personaId}_synthetic_script.md` ➜ 단톡방 대화록 흐름 속에 유저가 성향에 맞춰 뱉어내는 실전 행동 기록 및 리얼한 라이브 발화 스트림.

---

## 🛠️ 3. 가동 및 시뮬레이션 명령어 (Execution Protocol)

### 1단계: 생성 디렉토리 환경 및 API 토큰 유효성 검증
양산을 시작하기 전 `.env` 파일에 유효한 `OPENAI_API_KEY` 가 수립되어 있는지 확인하고, 아웃풋 타겟 디렉토리를 확인합니다.

### 2단계: 양산 팩토리 스크립트 단독 트리거 구동
```bash
# package.json에 명세된 ts-node 기반 자동 양산 명령어 가동
npm run automation:generate
```

### 3단계: 디스크 덤프 결과 유무 자동 검증
스크립트 가동 완료 후 `assets/stage_03_generated/` 하위에 각 페르소나별로 파일이 오차 없이 물리 배치되었는지 터미널에서 스냅샷 목록을 확인합니다:
```bash
ls -la assets/stage_03_generated/
```

---

## 🛡️ 4. 가선 자산 제어 및 멱등성 유지 정책 (Idempotency)

*   **출력 안정성 확보:** `runDatasetGenerator` 함수는 파일 생성 시 디렉토리 유무를 자동 감지하여 누락 시 `{ recursive: true }` 옵션으로 강제 선행 생성합니다.
*   **파일 유실 방어 가드레일:** 데이터 합성 작업 중 특정 페르소나의 API 요청이 비정상 실패하더라도, 전체 루프가 크래시되어 멈추지 않고 다음 유저의 자산 양산 단계로 예외를 우회 토스하는 `try-catch` 가드레일이 견고하게 내장되어 있습니다.
