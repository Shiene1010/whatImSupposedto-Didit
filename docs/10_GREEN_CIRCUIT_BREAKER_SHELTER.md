# 🟢 GREEN CIRCUIT BREAKER SHELTER
> **외부 API 장애 감지 회로 차단기 및 브라우저 로컬 IndexedDB 데이터 대피소 연동 명세서**

본 문서는 OpenAI API 인텔리전스 레이어나 원격 데이터베이스 서버 등 외부 서드파티 네트워크의 병목 및 다운 현상이 발생했을 때, 애플리케이션 전체가 마비되는 것을 막고 사용자가 타이핑한 마크다운 원문을 보존하는 **🟢 그린(Green) 장애 격리 및 고회복성 시스템**의 기술 명세를 정의합니다.

---

## ⚡ 1. API 장애 감지 회로 차단기 (ApiCircuitBreaker)

`ApiCircuitBreaker.ts` 모듈은 실시간 통신 스트림을 모니터링하여 네트워크 지연으로 인한 동반 크래시 및 시스템 좀비화를 차단하는 하드웨어 플러그인 스타일의 소프트웨어 설계입니다.

### ⚙️ 서킷 브레이커 3단 상태 전이 규칙 (State Machine)
1.  **CLOSED (회로 연결 - 정상):** 모든 요청이 정상적으로 백엔드 인프라로 전달되는 상태입니다. 연속 실패 카운트가 `0`으로 유지됩니다.
2.  **OPEN (회로 차단 - 위험):** **5초(5000ms) 초과의 타임아웃 지연 또는 네트워크 50x 에러가 연속 3회(`failureThreshold: 3`) 발생**하는 즉시 외부 통신 경로를 물리적으로 전면 차단합니다. 이후 모든 요청은 외부 서버를 찌르지 않고 즉시 로컬 대피소 콜백(`fallbackFn`)으로 리다이렉트됩니다.
3.  **HALF_OPEN (복구 기회 제공):** 회로가 열린 후 **10초(`cooldownPeriod: 10000ms`)의 쿨다운 타이머**가 경과하면 시스템은 자동으로 하프오픈 상태로 진입합니다. 라이브 트래픽 중 단 1개의 일회성 요청을 외부 API로 전송하여 성공하면 회로를 즉시 닫고(`CLOSED`), 실패하면 다시 닫힘 없는 `OPEN` 상태로 회귀시킵니다.

## 📦 2. 브라우저 로컬 IndexedDB 대피소 (LocalEmergencyStorage)

회로 차단기가 외부 통신 줄기를 닫아버리는(`OPEN`) 즉시, 시스템 프론트엔드 라우터는 사용자가 작성 중이던 마크다운 텍스트 자산을 사수하기 위해 브라우저의 격리된 안전 영속 스토리지인 `IndexedDB` 명세를 트리거합니다.

### 🛡️ 데이터 유실률 0% 사수 메커니즘 (Evacuation Routing)
*   **비동기 트랜잭션 적재:** 대피소 라우터가 발동하면 `LocalEmergencyStorage` 클래스는 `DidItEmergencyShelter` 데이터베이스의 `markdown_backups` 스토어를 개시하고 사용자의 원문 스트링 전체를 격리 임시 저장합니다.
*   **PENDING_SYNC 플래그 박제:** 대피 적재가 성공한 자산은 `syncStatus: 'PENDING_SYNC'` 메타 레이블이 찍히며, 네트워크 단절 상태에서 사용자가 브라우저를 새로고침하거나 창을 닫아도 데이터가 디스크 레벨에 영구 보존됩니다.

## 📡 3. 네트워크 복구 시 미동기 데이터 동기화 프로토콜 (Data Synchronization)

외부 클라우드 인프라 및 AI API 레이어가 완전히 복구되어 회로가 다시 정상 연결(`CLOSED`) 상태로 복귀하면, 백그라운드 가디언 프로세스가 대피소 데이터를 중앙 동기화합니다.

```text
[네트워크 복구 감지] ➜ 1. 서킷 브레이커 `CLOSED` 상태 전환 확인
                            │
                            ▼
[대피소 스캔 실행]   ➜ 2. `getPendingSyncPayloads()` 비동기 호출
                            │
                            ▼
[미동기 데이터 추출] ➜ 3. `syncStatus === 'PENDING_SYNC'` 상태의 대피 마크다운 전수 수집
                            │
                            ▼
[중앙 서버 이관]     ➜ 4. 백그라운드 스트림을 통해 Supabase 원격 테이블로 안전하게 일괄 이관(Bulk Insert)
                            │
                            ▼
[대피소 청소 완료]   ➜ 5. 이관 성공 확인 즉시 로컬 스토리지 내 임시 백업 행을 완전 삭제하여 캐시 해제
```
