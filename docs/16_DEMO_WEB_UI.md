# 데모 웹 UI

## 데모 목적

한 문장 목표와 실제 행동 기록을 입력해 작은 실행을 발견하고, 다음 행동을 더 쉽게 바꾸는 제품 흐름을 시연합니다. 목표 파싱, 발화 분리, 성취 신호 판정은 기존 `parseMarkdown`, `splitScriptByUser`, `evaluatePurpleKpi`를 브라우저에서 실행합니다.

## 사용 방법

1. `예시로 바로 체험`을 눌러 샘플 데이터를 불러오고 즉시 결과를 확인하거나, 목표와 기록을 직접 입력합니다.
2. `오늘의 작은 성취 찾기`를 누르면 4단계 규칙 기반 데모 처방과 KPI 판정의 근거가 표시됩니다.
3. 성취 배지는 키워드 기반 KPI 엔진 판정을 설명하며, 의미 이해나 임상적 평가를 뜻하지 않습니다.

## 개인정보와 생성 방식

- 입력값은 React 화면 상태에서만 사용되며 API나 데이터베이스로 전송하거나 저장하지 않습니다.
- 처방 문구는 데모용 템플릿이며 OpenAI 등 외부 AI 호출을 하지 않습니다.
- 처방 영역에 규칙 기반 데모임을 표시하고, 결과 하단에 실제 KPI 사용과 템플릿 생성 사실을 안내합니다.

## 실행 및 배포

로컬 실행은 `npm run dev`, 검증은 `npm test -- --runInBand` 및 `npm run build`를 사용합니다. 프로젝트의 기존 Vercel 배포 연결을 통해 기본 브랜치 변경 후 배포할 수 있습니다.
